# Surface: Cockpit 5 roles (standalone sample)

Operate. Standalone design sample (not production `apps/admin`). One page, five role views via switcher: super_admin, giam_doc_kinh_doanh, giam_doc_dao_tao, sale, giao_vien.

## Audience / job / action
Staff on office desktop ≥1440px. Job on arrival: see what is waiting for me and start the first item. Primary action: open the top queue row.

## Direction
