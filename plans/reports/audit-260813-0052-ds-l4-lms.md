## (3) Chất lượng UI LMS theo impeccable

Audience: học sinh (trẻ) + phụ huynh trên điện thoại. Mode Operate/Read, không ERP.

### Hierarchy

- Không trang nào dùng `Heading level={1}`. Login `level={2}` (`login.tsx:312`); đổi mật khẩu `level={3}` (`change-password.tsx:35`); còn lại `level={4}` + `.lms-page__title` 1.1rem.
- Topbar brand là `Text`, không heading (`student/home.tsx:123`). Nhiều trang **lặp tiêu đề** topbar + h4 (evidence, homework, consent, reset).
- Danh sách bài HS in **`item.type`** (`student/home.tsx:87`, `exercise.tsx:146`). API/test dùng enum `homework` / `test_periodic` (`apps/api/src/lms-ops/exercise-delivery.ts:193`). Học sinh thấy slug, không thấy tên bài.
- Chi tiết bài: `Lần phát` + 8 hex của UUID (`exercise.tsx:30-32,153-155`).

### Empty / error / loading

Có Banner/Spinner trên hầu hết query — tốt hơn nhiều admin-era placeholder. Lỗ:

| Lỗ | file:line |
|----|-----------|
| Sao trên home HS không có nhánh `error` | `student/home.tsx:22-34` |
| Exercise query fail = “bài không tồn tại” | `exercise.tsx:45-46,101-116` |
| ≥2 con, chưa chọn → thân trang trống | `parent/home.tsx:126-127,166` |
| Attendance query im lặng | `session-evidence.tsx:54-57` |
| Consent không đọc trạng thái hiện tại | `consent-settings.tsx:8-10,69-83` |
| Title lỗi hay chỉ `"Lỗi"` | `gifts.tsx:56`, `parent/home.tsx:85`, `report-card.tsx:80` |
| Kind-mismatch `return null` (flash trắng) | nhiều parent page |
| Đổi quà 1 tap, không confirm | `gifts.tsx:122` |
| `EmptyState` không được dùng | so với Banner info |

Loading route: spinner không chữ (`routes/index.tsx:29-34`). Không 404 — `*` → `/login` (`routes/index.tsx:82-83`).

### Mobile / responsive

- Cột 480px (`app.css:11-16`) ổn cho phone; desktop = dải hẹp giữa canvas `--cmc-surface-2`.
- `index.html:6` `maximum-scale=1.0, user-scalable=no` — **cấm pinch-zoom** (WCAG 1.4.4).
- Lưới 2/3 cột cứng; ảnh quà `height: 80` (`gifts.tsx:95`); ảnh buổi `height: 100` (`session-evidence.tsx:155`).
- Topbar HS: brand + 2 ghost `size="sm"` (`student/home.tsx:122-132`) dễ chèn trên 320px; spacer 60px giả cân bằng.
- Touch 44px chỉ áp cho `.astryx-button` / input (`astryx-theme-cmc.css:141-147`). Chip và card-div không được bảo vệ. Token ghi “Touch targets ≥44px separate” (`tokens.css:121`) — LMS không triển khai.
- `overflow-x: hidden` trên `body` (`app.css:8`) giấu overflow thay vì reflow.
- PageLoader `100vh` vs shell `100dvh` (`routes/index.tsx:31` vs `app.css:12`).

### Khả năng đọc cho học viên

- Meta `size="2xs"` = 12px, 12 chỗ (home, exercise, login helper, homework, evidence). Trẻ + phụ huynh lớn tuổi trên phone: dưới sàn đọc thoải mái.
- Helper đăng nhập HS đặc (`login.tsx:210-212`) cũng 2xs.
- In mật khẩu mặc định `Cmc2026@` trên banner (`change-password.tsx:44`) — dễ đọc nhưng lộ secret trên màn hình dùng chung (đã từng ghi nhận 2026-07-26).
- PDF bài tập chỉ là Banner + “Xem PDF” (`exercise.tsx:158-177`); handwriting ghi P2-debt.

**Tóm:** luồng chính (login → list → nộp / xem điểm / đổi quà) **đi được**. Craft consumer cho trẻ thì **mỏng**: hierarchy lệch, chữ nhỏ, identity bài kém, chrome copy-paste.

### Nên chia sẻ vs nên tách

**Chia sẻ (đã / cần siết):**

- Token `--cmc-*` (màu, type, space, focus, status).
- Primitive Astryx: Button, TextField, Banner, Badge, Spinner.
- Wordmark CMC EDU + xanh `#0071E3` — **không** giữ palette thứ ba ở admin login.
- Inter Variable (console.css vẫn khai `'Inter'` không Variable — `console.css:80`).

**Tách (đúng vai, không phải bug):**

- Density ERP vs consumer phone.
- Navbar module-switcher vs back/title/logout.
- Console composites: kanban, list, control bar, form sheet.
- Cột 480px vs full-bleed `.console-main`.

## (5) Khuyến nghị

### Lựa chọn: **giữ tách chrome + chia sẻ lớp token (đã có) + hoàn thiện primitive LMS**

Không hợp nhất `console.css` vào LMS. Không để `app.css` 85 dòng đóng vai “DS”.

Hành động cụ thể:

1. **Giữ** import stack hiện tại (token + Astryx, không Console).
2. **Mở rộng `app.css`** thành lớp LMS thật nhưng mỏng: `.lms-card`, `.lms-card--interactive`, `.lms-topbar__spacer`, `.lms-grid-2`, `.lms-grid-3`, `.lms-page--flush`, focus/hover chip+card. Map type sang `--cmc-fs-*`, space sang `--cmc-space-*` / `--cmc-pad-card`.
3. **Thêm `LmsTopbar` / `LmsPage`** (hoặc layout route) — xóa 7 spacer `width: 60` và title kép.
4. **Không** nhét `Panel`/`ListPage` Console vào LMS (density sai). `EmptyState` + `Banner` thì dùng được.
5. **Sửa đọc:** bỏ `user-scalable=no`; meta bài `sm` không `2xs`; title bài = tên không phải `type`; bỏ UUID trên UI.
6. Admin login: trả về `--cmc-brand`, đừng invent `#4f7dfb` (lane admin, nhưng là chỗ “khác hãng” mạnh nhất).

### Chi phí / rủi ro của lựa chọn này

| | |
|--|--|
| **Chi phí** | ~1–3 ngày agent: trích 5–7 class + 1 layout, thay ~77 inline, sửa copy/type. Không đụng `console.css`. Test: login, home HS/PH, nộp bài, đổi quà, 4 trang parent. |
| **Rủi ro thấp** | Chrome LMS đã tách; thêm class không đổi contract API. |

| **Rủi ro nếu giữ nguyên** | 77 inline tiếp tục drift; card/grid lệch nhau; chữ 12px + no-zoom tồn tại với học sinh. |
